# Text RPG

Text RPG is a Java command-line adventure game where the player chooses a character class, explores three dangerous areas, manages equipment and consumable items, and fights random encounters and area bosses before facing the final Dragon.

## Instructions for Build and Use

Steps to build and/or run the software:

1. Install JDK 21 or a compatible Java Development Kit, then open a terminal in the project directory containing `Main.java`.
2. Compile all Java source files with `javac *.java`.
3. Start the game with `java Main`.

Instructions for using the software:

1. Enter a player name and choose one of the ten classes: Warrior, Rogue, Mage, Paladin, Ranger, Berserker, Druid, Necromancer, Monk, or Bard.
2. Follow the numbered prompts to explore the Whispering Woods, Cursed Caverns, and Dragon's Wastes. Each area contains 15 random encounters followed by an area boss.
3. During combat, choose attacks, class special abilities, items, inventory, running away, or waiting. Manage health, equipment, experience, and status effects to defeat the Dragon and complete the game.

## Development Environment
